# 13F Top Ideas

An SEC 13F filing analyzer that shows what major hedge funds hold and how their positions change from quarter to quarter. It pulls 13F-HR filings straight from SEC EDGAR, adds tickers, market data and sectors, writes an AI-generated investment thesis for each position, and exports shareable PDF reports. It also has a Wayback Machine scraper that tracks team and portfolio changes on fund websites over time.

The code lives in [`13f-top-ideas/`](13f-top-ideas/). For a step-by-step walkthrough written for non-technical users, see the [User Guide](13f-top-ideas/USER_GUIDE.md).

## Features

- **Fund lookup by name.** Type a short name like `viking`, `pershing` or `berkshire` (24 funds are built in). Any other name is looked up in EDGAR, or you can pass a CIK directly.
- **Top-20 holdings with QoQ deltas.** Market value, shares, % of portfolio and quarter-over-quarter changes across up to 4 quarters of filings.
- **Enrichment.** Tickers from CUSIPs via OpenFIGI, plus price and sector data via `yfinance`.
- **Sector breakdowns and charts.** Holdings and sector charts drawn with matplotlib.
- **AI investment theses.** A short thesis for each position, generated by Llama through the Groq API.
- **PDF reports.** Branded reports built with `fpdf2`.
- **Website change tracking.** Finds a fund's team and portfolio pages and compares Wayback Machine snapshots year by year.
- **MCP server.** Offers the same data tools to any MCP-compatible AI client.

## Interfaces

| Entry point | What it is | Run |
|---|---|---|
| `bot_app.py` | Streamlit chat UI that takes questions in plain English ("What is Viking investing in?") | `streamlit run bot_app.py` |
| `app.py` | Interactive terminal app with colored tables, charts, theses and PDF export | `python3 app.py` |
| `sec13f.py` | One-shot CLI that writes a PDF report | `python3 sec13f.py viking -q 4 -o report.pdf` |
| `wayback_scraper.py` | Interactive tool for tracking team and portfolio changes | `python3 wayback_scraper.py` |
| `mcp_server.py` | MCP server (Python 3.10+) | `python3 mcp_server.py` |

`data_tools.py` holds the shared EDGAR, enrichment, LLM and Wayback logic that the bot and the MCP server use.

### MCP tools

`list_available_funds`, `search_fund`, `get_fund_holdings`, `get_holding_detail`, `generate_investment_thesis`, `get_sector_breakdown`, `track_website_changes`

## Architecture

```
SEC EDGAR ──► CIK lookup ──► 13F-HR filing list ──► info-table XML ──► parse holdings
                                                                          │
                          OpenFIGI (CUSIP → ticker) ◄─────────────────────┤
                          yfinance (price, sector)  ◄─────────────────────┤
                                                                          ▼
                        compute top-N + QoQ deltas ──► LLM thesis ──► table / chart / PDF
```

## Setup

```bash
cd 13f-top-ideas
pip install -r requirements.txt
```

**LLM key (optional).** AI theses and the chat bot's answers use the [Groq API](https://console.groq.com/keys), which has a free tier. For the Streamlit bot, copy `.streamlit/secrets.toml.example` to `.streamlit/secrets.toml` and set `GROQ_API_KEY`. For the terminal app, run `export GROQ_API_KEY=...`. Everything except the AI features works without a key.

**MCP server (optional).** Requires Python 3.10+ and `pip install "mcp[cli]"`.

## Example

```bash
python3 sec13f.py "pershing square" --quarters 4 -o ~/Desktop/pershing.pdf
```

## Tech stack

Python · Streamlit · pandas · requests · BeautifulSoup · yfinance · matplotlib · fpdf2 · Groq · Model Context Protocol

## Notes

- SEC EDGAR requires a descriptive `User-Agent` and rate-limits requests. The client throttles itself to stay within those limits.
- 13F filings are delayed by up to 45 days after quarter end and cover only long U.S. equity positions. This tool is for research and is not investment advice.
